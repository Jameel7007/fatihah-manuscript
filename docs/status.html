Running it

Dev server is registered as fatihah in launch.json (port 4521). Asset pipeline is deterministic — rebuild anything, the checksums must match.

# see the piece (scroll = p)
npm run dev                      # → localhost:4521

# judgment proofs & QA scenes (URL params)
/?scene=proof&layout=7&bg=parchment    # the v1.5 page on aged ground (&export=1 → 4000px PNG)
/?capture=0.710&tier=1                 # deterministic frame + SHA-256   (&nogeo = emboss-only A/B)
/?scene=inkrt&p=0.45                   # flat ink-RT instrument (R=coverage, G=wetness)

# asset pipeline (each step verifies the one before)
node build/verify-text.mjs       # pin + verify canonical text
node build/shape-text.mjs        # shape → frozen composition (v1.5 centered + rosette)
node build/build-ink-atlas.mjs   # MTSDF + stroke-order atlases + instances
node build/build-glyph-mesh.mjs  # §6 bevel relief mesh → glyphs.bin
node qa/silhouette-diff.mjs      # M4 silhouette DoD (needs the capture pairs)
