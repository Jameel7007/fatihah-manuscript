Al-Fātiḥah 3D Manuscript

One aged parchment bearing the seven āyāt, floating in darkness, transformed by scroll: rolled → unrolled → written → presented → embossed → risen → facing. Every value below is typed into code, not interpreted. Stack: Three.js WebGPURenderer + TSL node materials, WebGL2 fallback from the same node graph.

01

Overall composition

A single portrait sheet (0.78 × 1.00 world units) floats near the origin in a warm near-black void (#0D0906). The sheet lies in the world XZ plane when flat, +Y up, top of the text toward −Z. It is the only bright object; everything else — dust, fog, faint construction traces — sits at least 20× darker. Historic register: broad Abbasid–Mamluk folio proportions, iron-gall ink, gilding over red bole. Suggestive, never a facsimile of any extant manuscript.

All animation is a pure function of one smoothed scroll uniform uP. The only non-deterministic element is a residual inertia field that decays to zero and is disabled for regression capture (§17). The seven states share one axis with explicit overlap zones — every boundary is a crossfade, never a cut:

Tone & color commitment

AgX tone mapping (THREE.AgXToneMapping), not ACES. The palette lives in warm ambers under a 3400 K key; ACES skews saturated warm highlights toward yellow-white and clips gold speculars harshly. AgX's slower shoulder keeps gilt highlights gold and holds the near-black floor without crushing. Cost: mild mid-tone desaturation — compensated with a fixed +0.05 saturation in the grade pass (§16), not by pushing texture chroma. Linear workflow throughout; outputColorSpace = SRGBColorSpace; all hex values in this document are sRGB with linear conversions given where a uniform is set from them.

04

Rolled silhouette (spline control points)

The curl is analytic and arc-length preserving: material beyond a moving curl line wraps onto an Archimedean spiral whose radius grows outward by one sheet thickness per wrap, r(θ) = r_core + (t/2π)·θ, t = 0.0009. Spirals are given by parameters (exact by construction); the free web between them is a centripetal Catmull-Rom through the control points below. Units: sheet-local, long side = 1.0; side profile in (z, y) at u = 0, pose tilt removed.

Thin-stroke guard rule, derived from supplied geometry

Calligraphic hairlines (~0.03 em ≈ 0.0017) are narrower than 2b, so an unguarded bevel self-intersects. Per boundary vertex, sample interior half-width w from the SDF's distance-to-skeleton channel, then:

wScale = clamp(w / (b + 0.0004), 0.25, 1.0)   // shrink profile inset
hScale = clamp(sqrt(wScale), 0.55, 1.0)        // partial height follow
profile' = profile × (inset: wScale, height: hScale)

Hairlines become rounded gilded beads at 55–100% depth — exactly how burnished gesso relief behaves on thin strokes. The guard is computed at build time and baked into the mesh.

Parchment thin-surface translucency TSL, single pass

// wrap-lit back-transmission; no refraction pass needed at 0.37 mm
backLit  = saturate((dot(-N, L) + 0.4) / 1.4)                 // wrap w = 0.4
thick01  = fiberHeight * 0.6 + macroThickness * 0.4            // from fiber pack A + utility pack
trans    = backLit * transColor * (1.0 - thick01) * 0.18       // transColor #B08D52 → (0.442, 0.271, 0.083)
diffuse += trans * keyColor                                    // key + rim only; env excluded (too flat)

Justification: at 0.37 mm true SSS is invisible except against the light — the wrap term reproduces the one observable phenomenon (glowing edges and curls when the rim light crosses behind) for the cost of three MADs. The curl states are where it earns its place: inner wraps light up amber.

Authored environment map

A dark room holding one warm light: near-black walls (#050403 base, +0.5 EV brown gradient toward the floor), one tall 2.2:1 warm window (3200 K, luminance 6× diffuse white) placed 35° left of +Z at 20° elevation — its vertical rectangle is the signature shape the gold bevels reflect. A cool 4500 K floor-bounce card opposite at 3% window luminance, and three 0.5%-area 3000 K pinpoints (distant lamps) scattered right hemisphere for bevel sparkle variety. Authored in Blender at 2048×1024 EXR, shipped at 1024×512. PMREM at load; roughness-prefiltered mips are what the burnish map indexes.

Contact shadows — the signature moment, named

Two cooperating techniques. (a) PCSS above gives the directional, contact-hardening component. (b) A height-field blob pass: glyphs only, rendered orthographically from below (frustum 0.9 × 1.15, 512² R16F storing height-above-sheet), blurred by two separable passes with radius_texels = 2 + 640·h, then composited into the parchment BRDF as ×(1 − 0.75 · C · exp(−h / 0.12)). Authored blur, zero sampling noise — this is what survives a 390 px viewport, where PCSS alone dissolves into its filter. As letters leave the sheet in S7, the blob decays exponentially while PCSS takes over: the risen text leaves a faint soft pool, then a long soft cast shadow across the empty page.

Ink-to-geometry transition mechanism

The single hardest moment to keep pop-free. Three stages, one invariant: flat SDF and extrusion are generated from the identical flattened polylines (§17), and the extrusion's top face carries the same atlas UVs — so plan-view contours are equal by construction, not by tolerance.

  1. Flat ink (p < 0.640). Ink is a layer inside the parchment surface shader: MTSDF coverage with analytic fwidth AA, colored by the wet/dry blend, sunk −0.0006 into fiber valleys via the cavity term. No geometry exists.
  2. Emboss (0.640–0.695, E2). A precomputed puff-height channel (interior-distance1.6, clamped, 1.5-texel pre-blur, stored in progression-atlas A) scales from 0 → 0.0009. Its screen-space gradient perturbs the parchment normal; the same height feeds a +8% cavity darkening around stroke borders — fibers compressing under the forming relief. Pure normal-map relief: zero vertices move.
  3. Geometry handoff (0.680–0.720). The merged glyph mesh appears at depth 0.0009 — exactly the emboss's apparent height — then all clusters lift uniformly to 0.0012 while emboss normal strength runs 1 → 0. No alpha fade anywhere: the mesh enters opaque, and because its silhouette equals the SDF contour and its top-face material samples the same SDF ink color, the only observable change is parallax of ≤ 0.3 px at 1440p (depth 0.0009 under the 83° camera). The flat ink layer keeps rendering beneath the caps, holding the root-fillet crevices ink-dark.

Material transmutation. The mesh is born ink: top face uses the flat-ink color and roughness at emergence. During each cluster's rise window (lagging rise by 0.25 of the window, ease E2), base color, metalness, roughness, and anisotropy blend to the §7 gold set — sidewalls resolve from wet-dark to patina gold. The written word does not get gilded by a crossfade; it turns into gold as it takes form. Depth resolution: depth(cluster) = max(uniformLift(p), stagger_i(p)) so the handoff and the stagger can overlap without a discontinuity. After the caps fully occlude the flat layer, the flat ink fades 0.78–0.84 to the 8% ghost stain (§7) — never visible as a fade because it is occluded while it happens; it reappears only when the text lifts away in S7.

Simulation design

Deliberate deviation — sim as residual, not primary

The brief offers PBD cloth or analytic curl. A free-running PBD unroll is history-dependent: scrubbing backward cannot revisit the same shapes, violating the deterministic-p requirement. So: the analytic curl field is the pose; XPBD contributes only a residual displacement excited by scroll velocity and decaying to zero. Determinism at rest, physicality in motion, and the residual is exactly the part regression capture turns off.

Parchment solver

  • Pose: surfaceEval computes flat map → cup → CR web sag → spiral wrap per end (arc-length preserving, §4) → pose tilt → recede, all closed-form in p. Boundary silhouette (§5) baked as a per-vertex inset mask.
  • Residual lattice: 48×64 XPBD points over (u, v). Constraints: stretch (compliance 0, inextensible) + bending (compliance 1e-5). 6 iterations, dt clamped to 1/60, velocity damping exp(−3.5·dt), border pinned. Excitation: a = −n̂ · 0.35 · v_scroll_lpf, clamped |a| ≤ 2.0, applied strongest where wrap curvature is highest (the paying-out region carries the inertia). Settle to < 0.5 px in ≈ 0.9 s. The mesh samples the lattice bilinearly and adds it along the pose normal.
  • Normals: P2 central-differences the final position texture (pose + residual), so lighting always sees true geometry; analytic Jacobian only at the two boundary rings where the stencil is one-sided. Nothing is approximated from the undeformed mesh.
  • T3 substitute: residual replaced by a traveling damped wave 0.004 · v_lpf · sin(28(v − v_front)) · exp(−9|v − v_front|) behind the unroll front — same visual grammar, zero dispatches.

Ink SDF pipeline

  • Build: supplied SVG → checksum gate → adaptive flattening (tolerance 0.0015 em) → per-cluster MTSDF via msdfgen (mtsdf mode: RGB multi-channel + A true SDF), 64 px/em, pxrange 6. Resolution rule per glyph: texels/em = clamp(⌈6 / minStrokeWidth_em⌉, 48, 96).
  • Stroke-order field w: rasterize cluster at 4× → Zhang-Suen skeleton → geodesic distance from the cluster's RTL entry point, normalized, dilated outward to fill the glyph → progression atlas R. Supplied path order (digitized stroke order) breaks ties between branches. G = āyah id, B = bleed weight (fiber-map response baked at the glyph's sheet position — ink bleeds along fibers, so bleed is precomputed from the same fiber map the surface renders).
  • Runtime reveal: edge = uPWrite_āyah; coverage threshold sweeps w with smoothstep width 0.012 (E5). Wetness wet = 1 − clamp((edge − w)/0.045, 0, 1) drives color (wet→dry), roughness (0.09→0.58), and bleed: iso-offset 0.35·(fiber−0.5)·wet + 0.12·(fiber−0.5) in SDF units — edges wander ≤ 1.6 atlas px along fibers while wet and freeze at 35% of that. No history buffer; wetness is closed-form in p, hence scrub-safe.

Extrusion generation build time — never on mobile at runtime

  1. Same flattened polylines as the SDF step (the alignment guarantee).
  2. Self-intersection cleanup (even-odd resolve), winding normalization, cluster grouping (letters + their diacritics + marker per āyah share cluster ids).
  3. Thin-stroke guard sampling (§6) against the SDF interior-distance field.
  4. Bevel sweep: 9-point profile × contour, 8 rings + cap; caps earcut-triangulated; top-face UVs = atlas UVs; per-vertex: clusterId, bevel-ring index, baked root AO, curvature-roughness floor.
  5. Merge all clusters → one indexed mesh; quantized attributes (pos 14-bit, normal oct8, uv 12-bit); meshopt compress → glTF. Draco rejected: meshopt decodes 5–10× faster on mobile and streams.
