Overall composition

A single portrait sheet (0.78 × 1.00 world units) floats near the origin in a deep-blue universe (v1.6: floor #01030D — black with a blue cast — a whisper of a nebular lobe behind the sheet, tiny stars — §11; through v1.5 it was a warm near-black void #0D0906). The sheet lies in the world XZ plane when flat, +Y up, top of the text toward −Z. It is the only bright object; everything else — dust, the sky's lobe, the stars — sits at least 20× darker (the brightest stars excepted: a few pinpoints through the AgX shoulder). Historic register: broad Abbasid–Mamluk folio proportions, iron-gall ink, gilding over red bole. Suggestive, never a facsimile of any extant manuscript.

All animation is a pure function of one smoothed scroll uniform uP. The only non-deterministic element is a residual inertia field that decays to zero and is disabled for regression capture (§17). Tone & color commitment

AgX tone mapping (THREE.AgXToneMapping), not ACES. The palette lives in warm ambers under a 3400 K key; ACES skews saturated warm highlights toward yellow-white and clips gold speculars harshly. AgX's slower shoulder keeps gilt highlights gold and holds the near-black floor without crushing. Cost: mild mid-tone desaturation — compensated with a fixed +0.05 saturation in the grade pass (§16), not by pushing texture chroma. Linear workflow throughout; outputColorSpace = SRGBColorSpace; all hex values in this document are sRGB with linear conversions given where a uniform is set from them.

Layout of the seven āyāt

Uthmani text, Ḥafṣ ʿan ʿĀṣim, Basmalah counted as āyah 1. The supplied SVG composition is authoritative — the pipeline verifies it by checksum and never re-shapes, re-spaces, or detaches (§17, §18). This section defines the container the supplied artwork is placed into.

Glyph source of record — confirmed

The single calligraphic source is Amiri Quran (Khaled Hosny), licensed under the SIL Open Font License 1.1 — outlines shaped once through HarfBuzz into one fixed, fully-kerned SVG composition, then frozen and checksummed; that SVG, not the font, is what the pipeline consumes. OFL 1.1 permits embedding and derivative artwork of this kind; the “Amiri” reserved font name restricts only redistributed font software, which this project does not do. Everything derived from the source regenerates automatically on rebuild — the per-āyah timing windows (§10), the thin-stroke bevel guard (§6), and the stroke-order override table (§17) — so a later change of hand (e.g. commissioned calligraphy) is a full asset rebuild plus regression re-bless, not a spec change.

Thin-stroke guard rule, derived from supplied geometry

Calligraphic hairlines (~0.03 em ≈ 0.0017) are narrower than 2b, so an unguarded bevel self-intersects. Per boundary vertex, sample interior half-width w from the SDF's distance-to-skeleton channel, then:

wScale = clamp(w / (b + 0.0004), 0.25, 1.0)   // shrink profile inset
hScale = clamp(sqrt(wScale), 0.55, 1.0)        // partial height follow
profile' = profile × (inset: wScale, height: hScale)

Hairlines become rounded gilded beads at 55–100% depth — exactly how burnished gesso relief behaves on thin strokes. The guard is computed at build time and baked into the mesh.

Ink-to-geometry transition mechanism

The single hardest moment to keep pop-free. Three stages, one invariant: flat SDF and extrusion are generated from the identical flattened polylines (§17), and the extrusion's top face carries the same atlas UVs — so plan-view contours are equal by construction, not by tolerance.

  1. Flat ink (p < 0.640). Ink is a layer inside the parchment surface shader: MTSDF coverage with analytic fwidth AA, colored by the wet/dry blend, sunk −0.0006 into fiber valleys via the cavity term. No geometry exists.
  2. Emboss (0.640–0.690, E2). A precomputed puff-height channel (interior-distance1.6, clamped, 1.5-texel pre-blur, stored in progression-atlas A) scales from 0 → 0.0009 apparent height. Its screen-space gradient perturbs the parchment normal; the same height feeds a +8% cavity darkening around stroke borders — fibers compressing under the forming relief. Pure normal-map relief: zero vertices move.
  3. Geometry handoff — explicit overlap window p ∈ [0.690, 0.730], t = (p − 0.690)/0.040. No hard switch exists. Inside the window, both mechanisms run simultaneously: 
    geoDepth(t)   = 0.00045 + 0.00075 · E2(t)      // grows from HALF the emboss height → 0.0012
embossStr(t)  = 1 − E7(t)                       // E7 = cubic-bezier(0.37, 0, 0.63, 1)
    Geometry enters at a sub-emboss depth (0.00045 = 50% of the emboss's apparent height) so the eye never sees relief jump; its true height crosses the fading emboss at p ≈ 0.710, and the combined perceived relief is monotonically non-decreasing through the window. No alpha fade anywhere: the mesh enters opaque, its silhouette equals the SDF contour, and its top face samples the same SDF ink color — the only observable change is parallax ≤ 0.35 px at 1440p under the 83° camera — which holds through ≈ 0.71; §9 starts the camera retreat at 0.70, so by 0.730 the projection parallax reaches ≈ 1 px at ~66° elevation, occluded beneath the opaque caps and visible only as the flat layer's soft under-edge on one side (measured, M4 silhouette DoD). The flat ink layer keeps rendering beneath the caps, holding the root-fillet crevices ink-dark. Z-guard: geometry depth is floored at 0.00045 (never rendered shallower), the glyph main-pass pipeline carries depthBias −2 / slopeScale −0.5 during this window only (shadow and contact pipelines stay unbiased), and the base ring fetches its position from the same surface-field posTex as the parchment — the seam is watertight by construction, and at ≥ 0.00045 separation reversed-Z float depth has > 3 orders of magnitude of margin against z-fighting. Regression frame R-0.710 sits at the window midpoint (§20).

Material transmutation. The mesh is born ink: top face uses the flat-ink color and roughness at emergence. During each cluster's rise window (lagging rise by 0.25 of the window, ease E2), base color, metalness, roughness, and anisotropy blend to the §7 gold set — sidewalls resolve from wet-dark to patina gold. The written word does not get gilded by a crossfade; it turns into gold as it takes form. Depth resolution: depth(cluster) = max(geoDepth(p), stagger_i(p)) so the handoff and the stagger can overlap without a discontinuity (the first āyah's rise begins at 0.722, inside the handoff tail). After the caps fully occlude the flat layer, the flat ink fades 0.78–0.84 to the 8% ghost stain (§7) — never visible as a fade because it is occluded while it happens; it reappears only when the text lifts away in S7.

Simulation design

Deliberate deviation — sim as residual, not primary

The brief offers PBD cloth or analytic curl. A free-running PBD unroll is history-dependent: scrubbing backward cannot revisit the same shapes, violating the deterministic-p requirement. So: the analytic curl field is the pose; XPBD contributes only a residual displacement excited by scroll velocity and decaying to zero. Determinism at rest, physicality in motion, and the residual is exactly the part regression capture turns off.

Parchment solver

  • Pose: surfaceEval computes flat map → cup → web sag → spiral wrap per end (arc-length preserving, §4) → pose tilt (pivoted at the top curl line) → recede, all closed-form in p. The wrapped fraction is u-dependent — W_eff(u) = W_top + wLag(p)·(2u)² — so the center opens first and the edges lag, deterministically. Boundary silhouette (§5) baked as a per-vertex inset mask.
  • Residual lattice: 48×64 XPBD points over (u, v), expressed and solved entirely in the local tangent frame of the analytic pose — never world space. Each lattice point stores r = (r_t, r_b, r_n); the world offset is reconstructed per frame as 
    T = normalize(∂P/∂u)                    // analytic pose Jacobian, before residual
N = normalize(∂P/∂u × ∂P/∂v)
B = N × T
world(u,v) = P(u,v) + T·r_t + B·r_b + N·r_n
    Because the frame rotates with the wrap, a stored residual rides the roll surface at high curvature and cannot express a world-space offset that pierces an inner layer. Penetration clamps: |r_n| ≤ 0.0027 (3 t), |r_t|, |r_b| ≤ 0.004. Constraints: stretch (compliance 0) on frame-space neighbor differences with rest length 0, bending as a discrete Laplacian toward 0 (compliance 1e-5) — the residual is a decaying elastic field that provably vanishes at rest. 6 iterations, dt clamped to 1/60, velocity damping exp(−3.5·dt), border pinned. Excitation acts along frame N only: a_n = −0.35 · v_scroll_lpf, clamped |a| ≤ 2.0, weighted by wrap curvature (the paying-out region carries the inertia). Settle to < 0.5 px in ≈ 0.9 s. The mesh samples the lattice bilinearly.
  • Residual availability by platform: T1/T2 WebGPU — compute path above. T1/T2 WebGL2 — same solver as ping-pong RGBA16F fragment passes (12 tiny 48×64 passes/frame, cost negligible); if renderable float targets are missing (EXT_color_buffer_float family absent), the lattice is dropped, not approximated, and the T3 wave below takes over. T3 on any backend — lattice never runs; the wave term is the substitute.
  • Manual QA — the “R-flick” profile (regression capture disables the residual, so this layer is reviewed by eye). Dev builds bind key Q to a scripted target-p profile: hold p = 0.10 for 1.0 s → linear ramp to 0.30 over 0.5 s (dp/dt = 0.4 s⁻¹) → hold 1.5 s → three alternating flicks 0.30→0.22, 0.22→0.34, 0.34→0.26, each 180 ms (E1) → hold 3 s. Reviewer confirms: (1) trailing-edge lag is visible during the ramp; (2) ripple decays smoothly, dead by ≈ 1 s into each hold, no residual oscillation; (3) the web never penetrates the roll during flicks; (4) motion reads along the surface normal — no lateral “swimming”. Sign-off is part of M1's definition of done (§20).
  • Normals: P2 central-differences the final position texture (pose + residual), so lighting always sees true geometry; analytic Jacobian only at the two boundary rings where the stencil is one-sided. Nothing is approximated from the undeformed mesh.
  • Wave substitute (T3, and any backend without renderable float targets): displacement 0.004 · v_lpf · sin(28(v − v_front)) · exp(−9|v − v_front|) applied along the same frame N inside the surface-field evaluation pass, behind the unroll front — same visual grammar, zero extra passes.

Ink SDF pipeline

  • Build: supplied SVG → checksum gate → adaptive flattening (tolerance 0.0015 em) → per-cluster MTSDF via msdfgen (mtsdf mode: RGB multi-channel + A true SDF), 64 px/em, pxrange 6. Resolution rule per glyph: texels/em = clamp(⌈6 / minStrokeWidth_em⌉, 48, 96).
  • Stroke-order field w: rasterize cluster at 4× → Zhang-Suen skeleton → segment into branches at junctions → geodesic distance from the cluster's RTL entry point, normalized, dilated outward to fill the glyph → progression atlas R. Supplied path order (digitized stroke order) breaks remaining ties. G = āyah id, B = bleed weight (fiber-map response baked at the glyph's sheet position — ink bleeds along fibers, so bleed is precomputed from the same fiber map the surface renders). Three corrections are applied to the raw geodesic order:
    • Vertical-stem prior: a branch whose bounding box has height/width > 1.6 and arc length > 0.35 em (alif, lām, the ascenders of kāf, ṭāʾ, ẓāʾ, both stems of lām-alif) is re-parameterized top to bottom regardless of geodesic entry, then spliced back with a constant offset so w stays continuous at the junction.
    • Closed-loop tie-break (hāʾ, ṣād, ḍād, fāʾ, qāf, wāw, mīm): entry at the loop's upper-right; of the two candidate arcs at the junction, the arc whose initial tangent best aligns with (−0.71, +0.71) in page coordinates (y up) is traversed first — over the top leftward, returning along the bottom, matching the pen's counter-clockwise loop.
    • Diacritic scheduling: dots, harakat, and all detached marks of a word start Δp = 0.003 after the word's base-stroke group completes (≈ 0.12 s at design pace), ordered RTL then top-to-bottom within the word, spanning ≤ Δp 0.004 total. Baked into w at atlas build — no runtime branching.
    The build emits a per-glyph override table (build/stroke-order.json: clusterId → applied priors, loop entries, diacritic offsets, plus any hand overrides) — hand overrides are edits to this file, never to the atlas. An animated reveal of at least five words (one loop letter, one alif/lām stem, one diacritic-heavy word among them) is visually reviewed as part of M2's definition of done (§20).
  • Runtime reveal: edge = uPWrite_āyah; coverage threshold sweeps w with smoothstep width 0.012 (E5). Wetness wet = 1 − clamp((edge − w)/0.045, 0, 1) drives color (wet→dry), roughness (0.09→0.58), and bleed: iso-offset 0.35·(fiber−0.5)·wet + 0.12·(fiber−0.5) in SDF units — edges wander ≤ 1.6 atlas px along fibers while wet and freeze at 35% of that. No history buffer; wetness is closed-form in p, hence scrub-safe.

Extrusion generation build time — never on mobile at runtime

  1. Same flattened polylines as the SDF step (the alignment guarantee).
  2. Self-intersection cleanup (even-odd resolve), winding normalization, cluster grouping (letters + their diacritics + marker per āyah share cluster ids).
  3. Thin-stroke guard sampling (§6) against the SDF interior-distance field.
  4. Bevel sweep: 9-point profile × contour, 8 rings + cap; caps earcut-triangulated; top-face UVs = atlas UVs; per-vertex: clusterId, bevel-ring index, baked root AO, curvature-roughness floor.
  5. Merge all clusters → one indexed mesh; quantized attributes (pos 14-bit, normal oct8, uv 12-bit); meshopt compress → glTF. Draco rejected: meshopt decodes 5–10× faster on mobile and streams.
